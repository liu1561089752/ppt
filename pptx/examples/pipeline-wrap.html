换行的判据是每项的 flex-basis：没有声明宽度的项不会强行换行（它的 max-content 尺寸没有测量），所以统计条与标签云的布局可预期。
native flex wrap / align-content

换行之后，多出来的高度归谁

容器高度一旦定死，两行标签就不再一律贴顶：center 把整块行居中，space-between 把首末两行分别顶到上下边缘。每行的跨轴尺寸仍由共享的 flex 行求解器算，原生对象只是照着摆——所以两块面板的分行结果完全一致，差别只在分配。

同一个标签云放进不同高度的容器，浏览器只改变行的起点；转成原生对象后仍是可编辑的文本框与圆角矩形，没有整页位图。

native flex wrap / column direction

竖着排满一列，再开下一列

行方向换行是按宽度断行，列方向换行是按高度断列：条目先从上往下排，碰到容器高度就另起一列，列宽由条目自己声明的宽度决定，align-content 再把这些列分布在行内轴上。断列规则和分布规则都由同一份共享代码算，两种方向只是把主轴转了一下。
