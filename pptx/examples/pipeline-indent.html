text-indent

首行缩进是段落属性，文字仍然是可编辑文本

2EM 缩进

正文按中文排版惯例首行缩进两个字符，后面各行顶格。缩进只影响第一行，换行位置也因此少了一个字宽。

第二段同样缩进。导出后每段仍是 PowerPoint 里的一个段落，缩进写在段落的 pPr 上，可以在段落设置里直接改。

仅首段缩进

这一段带缩进，因为它是同类型元素里的第一个。

这一段没有缩进，哪些段落继承缩进由结构选择器决定。

6% 缩进

百分比缩进按父元素宽度解析，和 CSS 的定义一致。

卡片一窄，缩进的绝对值就随之变小。

对照：同一段文字，有无首行缩进

TEXT-INDENT: 0

首行不缩进时，段落的左边界是一条直线，读者靠段间留白来分辨段落从哪里开始，这也是西文排版的习惯。

TEXT-INDENT: 2EM

首行缩进两个字符时，段落起点一眼可辨，这是中文长文的传统做法，也是公文与教材的常见要求。

缩进值支持 em、px 与百分比；负数（悬挂缩进）需要内边距配合，当前会上报而不是半途应用。
