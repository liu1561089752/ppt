native grid / explicit lines

把元素钉在指定的行列线上

同一块画布，这次每个分区自己说明占哪几条线：标题横跨前两条列线，注释占满第三列的两行，脚注用 grid-area 落在第二行第一列，剩下的单元自动补位。

横跨两条列线

1 / 3

grid-column: 1 / 3 从第 1 条线到第 3 条线，宽度等于两条轨道加一个间隙。

钉在第三列，跨两行

grid-column: 3 与 grid-row: 1 / span 2 一起用：列固定，行跨两条轨道。

负线号也可以写：-2 / -1 就是最后一列。

grid-area 四值简写

行首 / 列首 / 行尾 / 列尾，等价于四条长写属性。

自动补位

没有声明位置的单元填进还空着的格子，文档顺序不变。

native grid / alignment in a cell

块在自己的格子里怎么对齐

容器声明 justify-items: center，于是每个块在自己的轨道里居中；声明了宽度的块保留自己的宽度，而不是被拉伸成整条轨道；需要时单个块可以用 justify-self 改回 end 或 stretch。

居中，220px 宽

宽度由块自己声明，居中来自容器。

同样的规则

轨道宽度不同，居中结果也不同。

justify-self: end

justify-self: stretch

显式拉伸的块仍然占满整条轨道：这是声明出来的，不是默认行为。
