同一张照片，三种取景

照片被塞进一个固定比例的画框里时，多出来的部分要裁掉。裁哪一块由 object-position 决定，object-fit: cover 保证不变形。三格用的是同一张图。

居中 · 默认取景点，画面重心被平均地切开。
20% 80% · 视线向下，留出上方天空。
right top · 贴住右上角，左边内容被裁走。

宽幅那张用 50% 30%：横条画框比照片扁得多，裁掉的是上下两端。

media · 背景

背景图也要说清尺寸

CSS 背景图不是 <img>：它默认按原始尺寸画，可以铺满、可以按像素给宽，也可以同时写死宽高。四种写法在同一块底色上排开。

auto · 原始像素大小，居中不放大。
120px · 只给宽，高等比推出来。
320px left top · 比框大，于是被框裁掉一角。
100% 100% · 拉伸铺满，比例不再保留。
先画底色，再画图，最后画字

背景图压在同一条规则的 background-color 之上，卡片里的文字又在图之上。这三层的顺序在原生对象里也必须保持，否则一张带图的卡片就只剩一块底色。

第四块的图被拉伸了：100% 100% 明确要求填满，好看与否是设计的选择。

图片条：卡片自己带一张图

图片条是卡片的背景，文字压在它下面（DOM 顺序里在它后面）。三张卡片等高，图片条高度一致，文字长度不同。

media · 色调

照片的色调也能写进文件

filter 不是栅格化：它落在图片的 a:blip 上，成为 grayscl、lum、alphaModFix 三个颜色变换。照片还是那张照片，换回原色只差删掉一行，画质不重采样。

grayscale(1) · 写成 a:grayscl，整张去色。
contrast(1.25) brightness(0.85) · 一个 a:lum 写两个数。
opacity(0.55) · a:alphaModFix，压成半透明。

对比度是精确换算（两边都绕 0.5 缩放）；亮度是近似——CSS 乘、DrawingML 加，中间调一致、两端分开，报告里会写明。

同一个盒子，三种尺寸

CSS 的 scale() 不改变布局，只改变画面：下面三个卡片占据的是同样的槽位，画出来却一个比一个大。原生对象里这就是「盒子按中心放大，盒子里的字号、圆角、内边距、描边一起放大」。1.0 是参照，1.18 是强调，0.86 是退后。
