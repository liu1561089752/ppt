三列宽度写在 <colgroup> 里：区域 22%、口径 30%、其余留给数值。单元格的 width 是内容宽度，内边距与边框会把它撑宽——浏览器怎么算，导出的原生表格就怎么算。

Table · 盒模型

单元格的宽度是内容宽度

下面这张表用 table-layout: fixed 固定了列宽。第二列没有写 <col>，而是由表头单元格自己声明 width: 120px 并退回 box-sizing: content-box：两侧内边距各 14px，浏览器把它画成 148px 的列——宽度只算内容，内边距另加。

项目 状态 备注
列宽由 <col> 给定 200px 没有内边距，200px 就是 200px。
单元格 width: 120px 148px 内容 120px + 左右内边距 28px（默认 content-box）。
未声明的列 余量 表格宽度减去已知两列，剩下的都给这一列。
三个数值都对得上。 这一页的列宽、内边距与文字对位在浏览器与导出的原生表格里一致；若固定列宽之和超过表格宽度，导出的表会按比例缩进框内并写明差异——幻灯片没有让表格长大的余地。
原生表格对象：每个单元格仍是可编辑文本，列宽与行高是表格属性，不是图片。
Table · 行高

行高是最小值，不是固定值

表头行写 height: 44px，正文行写 height: 60px；最后一行只给 20px，但里面的文字比它高，于是这一行由内容决定高度——这正是浏览器的行为，导出的表格照抄。
