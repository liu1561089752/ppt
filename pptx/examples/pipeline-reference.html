从 HTML 到原生 可编辑 PowerPoint

这段内容由 DOM 分析、布局求解与样式映射自动转换而来，标题、正文、卡片、图片、表格仍然全部可编辑。

HTML → DOM Analyzer → Layout Analyzer → Style Mapper → Native Deck Spec

弹性行：三张卡片自动等宽

结构识别

DOM 分析器识别标题、正文、卡片与列表，而不是把整页当成一张图片。

62%

布局求解

flex 行、列与等宽网格由布局分析器求角，输出与原生引擎一致的几何。

1.8x

样式映射

颜色、字号、行距、圆角、阴影和渐变映射为可编辑的 DrawingML 属性。

100%

网格：图片与要点并置

转换阶段

  • DOM 分析：保留标题、正文、列表的语义层级。
  • 布局分析：解析绝对定位、块流、flex 与等宽网格。
  • 样式映射：颜色、字体、间距、圆角、阴影与渐变。
  • 输出：原生 Deck Spec，再由原生引擎写入 PPTX。
